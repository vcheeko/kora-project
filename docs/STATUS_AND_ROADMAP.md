# Project Status & Roadmap

## Status — August 2026

KORA is an **early-stage systems project moving from governance/prototyping toward an executable core**.

Work completed or substantially explored in private development includes:

- governance and human-authority concepts;
- controlled execution and fail-closed thinking;
- verification / review / evidence workflows;
- transaction semantics for request → authorization → execution → verification → state update;
- a local bridge concept for moving from chat instructions toward governed machine execution;
- natural-language continuation concepts instead of rigid command memorization;
- safe-parallelism rules for independent, reversible work.

These items should be understood as **prototype/research engineering**, not as claims of a production-ready platform.

## Next milestones

### M1 — Public collaboration surface
- public project explanation;
- collaborator / co-founder search;
- investor / mentor discovery;
- IP-safe architecture overview.

### M2 — Minimal KORA Core
- persistent project state;
- task/dependency model;
- intent classification;
- risk/authority model;
- checkpoint + receipt format.

### M3 — End-to-end execution loop
- one user goal;
- plan;
- one or more governed tools/agents;
- verification;
- persistent continuation across sessions.

### M4 — Real-project pilot
Use KORA on a real project rather than continuing to improve KORA only in isolation. Measure:

- task completion rate;
- human interventions;
- recovery from failures;
- verification quality;
- time saved;
- unnecessary governance overhead.

### M5 — Product UX
- simple status/dashboard;
- conversational control;
- later: voice / phone interaction.

## What success would look like

A user should be able to say, in normal language, **what they want done**. KORA should know enough about the project to choose the next valid action, execute within authority, ask only when necessary, verify the result and preserve state for the next session.
